# Sun Path Analysis

Analyze sunlight and shadows for architectural design.

## Capabilities

- **Sun path diagrams** - annual solar arc
- **Solar position data** - azimuth, altitude by date/time
- **Shadow plots** - building shadow analysis
- **Thermal comfort charts** - solar heat gain
- **日照 analysis** - sunlight hours
- **Daylight factor** - interior light levels

## When to Use

- Sun position analysis for a location
- Shadow analysis for buildings
- Annual sun hours diagrams
- Solar panel placement optimization
- Architectural design sun studies
