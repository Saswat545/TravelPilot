# Code to Diagram

Automatically generate architecture diagrams from source code.

## Capabilities

- **AST parsing** for Python, JavaScript/TypeScript, Go, Java
- **Import dependency mapping** - module relationships
- **Architecture diagrams** - system structure
- **Flowcharts** - control/data flow
- **Org charts** - team structure
- **Module diagrams** - package dependencies

## Output Formats

- Mermaid diagrams
- SVG files
- PlantUML

## When to Use

- "Visualize the architecture of this project"
- "Show me the dependency graph"
- "Draw a flowchart of this function"
- "Create a module diagram"
