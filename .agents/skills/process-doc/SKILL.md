# Process Documentation

Formalize business processes with flowcharts, RACI matrices, and SOPs.

## Capabilities

- **Flowcharts** - visual process maps
- **RACI matrices** - responsibility assignment
- **SOPs** - standard operating procedures
- **Exception handling** - edge cases and escalations
- **Decision trees** - branching logic

## When to Use

- Formalizing a process that lives in someone's head
- Building a RACI to clarify who owns what
- Writing an SOP for a handoff or audit
- Capturing exceptions and edge cases
- Documenting how work actually gets done

## RACI Format

| Process Step | Role A | Role B | Role C |
|-------------|--------|--------|--------|
| Step 1 | R | A | C |
| Step 2 | C | R | I |

**R** = Responsible, **A** = Accountable, **C** = Consulted, **I** = Informed
