# Timeline Builder

Generate interactive timeline HTML pages from JSON data.

## Features

- **Multiple layouts** - vertical, horizontal, dual-side
- **Collapsible details** - expand/collapse events
- **Custom colors** - theme per event or category
- **Interactive HTML** - clickable, animated
- **Responsive design** - works on all devices

## When to Use

- Project milestones
- Company histories
- Resumes / CVs
- Release logs
- Chronological data visualization

## Data Format

```json
{
  "events": [
    {
      "date": "2024-01-15",
      "title": "Project Kickoff",
      "description": "Initial planning phase",
      "category": "milestone"
    }
  ]
}
```
